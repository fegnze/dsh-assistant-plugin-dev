# 子任务模板

通过官方子 Agent 能力执行以下模板；先检查 provider 的 preset、model、outputSchema、depth 等能力。明确上下文 clean/inherited、读写范围、验收和结果；不要强制子 Agent 绑定主助理，不另起调度器。

## 契约调查（只读）
目标：列出所需 Service/Event/Slot 精确契约及来源，查明未知项。禁止编辑、安装、认证。返回少量接口、边界和证据路径，不复制全部文档。

## 实现（指定范围写）
目标：按批准 specs/design 完成给定范围。只修改指定目录；共享文件系统不碰他人范围。使用当前 Inspect 契约，运行有关检查。返回改动、测试、未覆盖项与风险。

## 审查（只读）
目标：按 diff 和相关上下文找正确性、权限、生命周期和分发缺陷。不得修复或提交。逐项给文件位置、触发条件、影响和最小修复；无发现也报告审查边界。

## 验收（明确允许效果）
目标：复现批准的验收场景，区分模拟/真实本地/宿主/远端证据。事先列明会改变的状态，仅使用允许的操作并恢复测试状态。不得自行认证、发布或重试有外部副作用的任务。
